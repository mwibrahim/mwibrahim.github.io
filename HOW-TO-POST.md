# How to publish a blog post (no coding needed)

1. Go to your repo on github.com: https://github.com/mwibrahim/mwibrahim.github.io
2. Open the `_posts` folder.
3. Click **Add file -> Create new file**.
4. Name the file `YYYY-MM-DD-your-title.md`, for example `2026-11-02-my-second-post.md`.
   Use dashes instead of spaces, and the date is the publish date.
5. Paste this at the top, changing the title:

   ```
   ---
   layout: post
   title: "Your post title"
   date: 2026-11-02
   ---
   ```

6. Write your post underneath. Plain text works. Optional formatting:
   - `# Heading`, `## Smaller heading`
   - `**bold**`, `*italic*`
   - `- bullet item`
   - `[link text](https://example.com)`
7. Click **Commit changes**. The site updates in 1-2 minutes.

To edit your profile, open `about.md` the same way and click the pencil icon.
